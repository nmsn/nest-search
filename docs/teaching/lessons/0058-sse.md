## §2. SSE 协议

### 2.1 是什么

```
SSE (Server-Sent Events) = 服务端单向推送
  - 基于 HTTP (长连接)
  - 浏览器原生支持 EventSource API
  - 服务端按行推数据
  - 简单, 不需额外库
```

### 2.2 协议格式

```
HTTP 响应头:
  Content-Type: text/event-stream
  Cache-Control: no-cache
  Connection: keep-alive

数据格式 (一行一条):
  event: <event-name>      ← 事件名 (可选)
  data: <data>            ← 数据 (必需)
  id: <id>                ← 消息 ID (可选, 用于断线重连)
  retry: <millis>         ← 重连间隔 (可选)

空行 = 消息结束

多行 data:
  data: line 1
  data: line 2
  
  → 客户端 data 字段 = "line 1\nline 2"
```

### 2.3 实际例子

```
服务端推:

  event: progress
  data: {"percent": 30, "message": "已同步 30%"}
  id: 1

  event: progress
  data: {"percent": 60, "message": "已同步 60%"}
  id: 2

  event: done
  data: {"total": 100}
  id: 3
```

### 2.4 浏览器使用

```javascript
// 浏览器端
const eventSource = new EventSource('/api/sync/ds/progress');

eventSource.addEventListener('progress', (e) => {
  const data = JSON.parse(e.data);
  console.log(`${data.percent}%`);
  // 更新 UI
});

eventSource.addEventListener('done', (e) => {
  console.log('完成');
  eventSource.close();
});

eventSource.onerror = (e) => {
  console.log('连接错误, 浏览器会自动重连');
  // EventSource 自动重连
};
```

**关键**：浏览器**自动重连**，服务端可以通过 `id` 字段知道客户端收到哪条，实现"断点续传"。

## §3. SSE vs WebSocket

| 维度 | SSE | WebSocket |
|------|-----|-----------|
| 通信方向 | 单向 (服务端 → 客户端) | 双向 |
| 协议 | HTTP (长连接) | ws:// (升级) |
| 浏览器支持 | 100% (EventSource) | 100% |
| 自动重连 | ✅ 浏览器原生 | ❌ 需自己实现 |
| 房间/命名空间 | ❌ 需自己实现 | ✅ Socket.IO 内置 |
| 代理友好 | ✅ (HTTP 兼容) | ⚠️ 某些代理不友好 |
| 复杂度 | 简单 | 中等 |
| 适合 | 单向通知 | 双向/复杂 |

### 3.1 选哪个？

```
✅ 用 SSE:
  - 同步进度
  - 订单状态
  - 通知/告警
  - 日志流 (服务端单向输出)

✅ 用 WebSocket:
  - 聊天
  - 实时协作 (Google Docs)
  - 游戏/帧同步
  - 双向控制

❌ 都不用, 用 HTTP 轮询:
  - 实时性要求低 (5s 延迟可接受)
  - 后端简单
```

## §4. NestJS SSE 实现

### 4.1 安装

NestJS 11+ 内置 SSE 支持：

```bash
pnpm add -w @nestjs/platform-express  # 已装
# NestJS 11 自带 @Sse 装饰器
```

### 4.2 基础 endpoint

```ts
// sync.controller.ts
import { Controller, Sse, MessageEvent } from '@nestjs/common';
import { Observable, interval, map } from 'rxjs';

@Controller('api/sync')
export class SyncController {

  // SSE endpoint
  @Sse('progress/:businessLine')
  progress(@Param('businessLine') businessLine: string): Observable<MessageEvent> {
    // 定时推送进度
    return interval(1000).pipe(
      map((num) => ({
        data: { 
          businessLine,
          percent: num * 10, 
          message: `已同步 ${num * 10}%` 
        },
      })),
    );
  }
}
```

### 4.3 实际业务：同步进度推送

```ts
// sync.service.ts
import { Subject, Observable } from 'rxjs';

@Injectable()
export class SyncService {
  // 同步进度流 (每个业务线一个流)
  private progressStream$ = new Subject<MessageEvent>();

  // 业务方订阅
  getProgress$(businessLine: string): Observable<MessageEvent> {
    return this.progressStream$.pipe(
      filter((e) => e.data?.businessLine === businessLine),
    );
  }

  // 同步时推送
  async triggerFullSync(businessLine: string) {
    this.progressStream$.next({
      data: { businessLine, percent: 0, message: '开始' },
    });

    for (let i = 10; i <= 100; i += 10) {
      await this.doSync(businessLine, i);
      this.progressStream$.next({
        data: { businessLine, percent: i, message: `${i}%` },
      });
    }

    this.progressStream$.next({
      data: { businessLine, percent: 100, done: true },
    });
  }
}
```

```ts
// sync.controller.ts
@Sse('progress/:businessLine')
progress(@Param('businessLine') bl: string) {
  return this.syncService.getProgress$(bl);
}
```

### 4.4 完整流程

```
前端:
  const es = new EventSource('/api/sync/progress/ds');

  es.addEventListener('progress', (e) => {
    updateProgressBar(JSON.parse(e.data));
  });

后端:
  1. 用户调 POST /api/sync/full/ds (触发同步)
  2. sync.service 推 {percent: 0}
  3. 推 {percent: 30}
  4. 推 {percent: 60}
  5. 推 {percent: 100, done: true}
  6. 前端 EventSource 收到所有事件
  7. 前端 EventSource.close() (收到 done)
```

## §6. 鉴权

### 6.1 SSE 怎么鉴权？

```
SSE 是 HTTP, 鉴权跟 HTTP 一样:
  - Header 带 JWT
  - Guard 验证
  
但 EventSource 不支持自定义 header
  - 解决: 用 cookie 鉴权 (TGC)
  - 或: token 放 query string (?token=xxx) (不推荐)
  - 或: POST + EventSource polyfill
```

### 6.2 nest-search 鉴权集成

```ts
@UseGuards(CasGuard)  // CasGuard 验证 JWT (cookie 或 header)
@Sse('progress/:businessLine')
progress(@Param('businessLine') bl: string) {
  return this.syncService.getProgress$(bl);
}
```
